# 附近自动打怪

适用本次实测角色：Forever 1.60.1、盗贼、洛克莫丹。当前键位2邪恶攻击、4切割、3剔骨，每个目标开场242223，之后持续2，默认750ms。键位或职业变化后须重新适配。

1. 装备先修好，背包留空位，备足食物及剥皮刀。开启游戏自动拾取和按F交互。将食物放主动作条第12格（=），剥皮技能放第7格（7）。程序会核对7键确为当前等级剥皮技能，食物数量不能为0。
2. 将随包 `WoWProbe` 文件夹放进当前客户端 `Interface/AddOns`。本机已安装；更新插件后在游戏输入 `/reload`。左上色块及两条小血条必须可见，避免窗口、鼠标提示遮挡。
3. 角色放在适合自身等级的怪物附近，关闭聊天输入框。双击包内 `启动自动打怪.cmd`，保留“击杀后剥皮（7键）”。5秒倒计时后运行，保持游戏前台。
4. 脱战时仅主动攻击反应值4的黄名怪；未知反应、红名及友好目标均跳过，已在战斗时可处理可验证的攻击者。使用Tab循环附近活目标，避免按固定名称反复选到刚杀死的尸体。程序确认同一怪物死亡后，等待脱战、核对尸体、F拾取；收到拾取窗口开启和关闭事件后才按7剥皮，并等待专门的剥皮成功事件，再找下一只。不可剥皮、失败或超时会跳过，并写明原因。
5. 脱战血量低于80%按=吃食物，等待接近满血；启动和复活后也先恢复。盗贼能量不触发饮水。食物耗尽会停止，需要补充后再开始。
6. 停止可按住F12，或切出游戏点击工具“停止”。切出游戏会立即取消输入；结束后检查聊天输入框是否关闭。每轮最多10分钟、复活最多3次。

## 死亡恢复边界

`quick-corpse-route.json` 只适用于实测洛克莫丹墓地及南侧区域，路线标定与本机匹配；不能用于任意地图或跨障碍尸体。程序读取真实释放/复活按钮及尸体坐标，在已配置路线范围内跑尸；没有可靠路线、按钮或新鲜状态时停止，不自动选择灵魂医者。复活后等待两帧生命恢复，再吃食物到满血后继续。

此附近入口不自动售卖或修理。原完整流程的商人路线需另外录制和验收。测试开始前修好装备，不代表自动修理已实现。

## 查看记录

程序旁 `runtime` 目录自动保存每轮 `quick-日期-时间.log`、`-frames.tsv` 和目标、击杀、拾取、剥皮等关键PNG截图。击杀、拾取、剥皮分别计数；按键发送、目标消失、一次动画均不直接算成功。实际时间和证据文件见 [现场记录](live-combat-2026-11-17.md)。
