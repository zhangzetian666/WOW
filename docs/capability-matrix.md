# 客户端能力与实机验收矩阵

版本 0.5.0。Windows 工具、C#5 / .NET Framework、Lua 5.1 及三面板协议已实现；实际游戏电脑为 Windows 11，客户端具体版本尚未确认。以下“实现”表示开发代码和模拟能力，不代表该私服客户端已经支持或通过验收。

| 功能 | 实现依据 | 必要条件与受限行为 | 实机状态 |
| --- | --- | --- | --- |
| 状态读取 | WP1 坐标、方向、血蓝、目标、地图与空位 | 序号持续更新、校验有效；窗口/色块定位须实测 | 待测 |
| 战斗扩展 | WC3 完整名称哈希、GUID 哈希、可攻击性、动作条、事件 | 必要字段未知时停止；玩家不会进入怪物攻击流程 | 待测 |
| 目标接近 | 同地图可靠目标坐标、动作射程和地图标定 | 旧客户端不能可靠提供敌方位置时关闭接近；不猜方向追逐 | 待测 |
| 路线与返回 | 用户录制的 farm / corpse_run / vendor_return | 同图、连接点、允许逆序和实际可走地形；死亡回程也要求打怪路线允许逆序，非通用寻路 | 待测 |
| 释放灵魂 | 默认 StaticPopup 的 DEATH 类型及真实按钮矩形 | 死亡、零血、不同新帧确认后只点一次，须观察到幽灵 | 待测 |
| 尸体/复活 | 当前尸体坐标、恢复冷却、RECOVER_CORPSE 按钮 | 冷却未知、他人复活邀请、未知弹窗或路线不可达均停止 | 待测 |
| 包满检测 | 当前空位、错误观察能力和不同帧确认 | 空位持续 0 等待确认；提示与空位矛盾时暂停 | 待测 |
| 商人选择 | 用户确认的 F6 选取宏、保存的 NPC 全名及实时身份 | NPC 不可攻击且非玩家；商店 npc 身份须独立匹配 | 待测 |
| 逐格售卖 | 库存版本、完整占用位图、元数据、可见格矩形 | 默认灰色；保留消耗品、任务物品、保留 ID；未知不售卖 | 待测 |
| 售卖结果 | 新库存版本、原格为空、空位增加 | 不用其他格变化或重复事件推定成功；不确认弹窗或删除物品 | 待测 |
| 自动清包服务器 | 手动启用 AutoCleanOnly，库存和空位恢复 | 默认关闭；没有服务器实际证明时使用逐格策略或人工处理 | 待测 |
| 头像辅助比较 | 已保存 PNG 与当前头像的有界相似分数 | 默认关闭，启用后未知/过期/不符会停止；名称与实时身份仍必需，没有 OCR / 无插件回退 | 待测 |
| 键鼠保护 | 前台窗口、F12、边界、25ms 监控、有界按下/释放 | 实机确认和 5 秒倒计时；发送/释放失败锁存，须人工检查重启 | 待测 |
| 运行证据 | JSONL、失败截图、有限保留、导出报告 | 观察与计划分开，截图不可用要记录；预览绘制不等于桌面抓图 | 待测 |
| 长时间闭环 | 真实状态机驱动两小时虚拟环境及重复中断 | 虚拟时长与实际执行耗时分列；真实游戏连续两小时仍须验收 | 待测 |

## 版本与布局适配

| 客户端/环境 | 开发侧适配 | 必须现场确认 |
| --- | --- | --- |
| 3.3.5 / 接口 30300 | 当前插件加载候选基线；兼容旧容器元组、默认背包按钮 ID、旧地图接口 | 私服 API、物品类型/任务分类接口、尸体恢复延迟、动作条绑定与默认弹窗 |
| 较新客户端 | 对部分 C_Map、C_Container、C_Item 接口提供能力检测分支 | 接口内容、事件参数、UI 与受限制值的可读性；无对应能力则停止 |
| 自定义背包/弹窗插件 | 无法验证的物品格和按钮不发布可点击矩形 | 使用默认界面验证，或基于反馈增加明确的读取适配 |
| 多显示器/缩放变化 | 以物理像素、当前 client 尺寸及布局签名约束 | 重定位面板、重新核对标定与布局；三面板和目标按钮不得被遮挡 |
| 当前开发桌面 | 本轮专用模拟色块窗口已通过真实桌面捕获和数据解析，无输入、未连接游戏 | 先前第三阶段原生句柄错误保留为历史；预览支持有标记绘制回退，回退不算真实桌面通过 |

WO4 库存支持 0–4 号背包、每包最多 40 格，轮流发布一格元数据及全量支持范围内的占用位图。超范围、未缓存物品、分类来源缺失、没有完整可见按钮映射等情况保留为未知，不通过默认 false 放行售卖。

旧客户端的 GetItemInfo 返回值可能没有数字类别，且相关类别查询 API 也可能缺失；这时消耗品分类保持未知，逐格售卖不会把它视作普通物品。服务器自动清包是一项须单独实测的可选能力。

## 验收顺序

先完成只读与单次输入，再验证短路线和战斗单点；随后分别重复死亡和包满流程，最后验证完整连续运行。每一步记录客户端/职业/地图/配置及通过、失败或未测，不用模拟结果补写实机通过。详见 [完整指南](complete-testing.md) 和 [开发侧验证记录](verification.md)。

接口实现参考：[3.3.5 背包按钮与售卖处理](https://github.com/tekkub/wow-ui-source/blob/3.3.5/FrameXML/ContainerFrame.lua)、[3.3.5 商人窗口](https://github.com/tekkub/wow-ui-source/blob/3.3.5/FrameXML/MerchantFrame.lua)、[SendInput](https://learn.microsoft.com/en-us/windows/win32/api/winuser/nf-winuser-sendinput)。这些资料用于实现适配分支，不能证明目标私服客户端兼容。
