# 换电脑使用与当前交付范围

目标是完成首次配置后点击开始即可运行。当前附近打怪版本仍在实机联调，不能把本机的部分成功记录当作其他电脑已经验收。

| 自动拾取、剥皮 | 已有一轮击杀→拾取→剥皮→继续扫描实机记录；多只连续完整流程待验收 |

## 首次换电脑

应发送完整启动包，不能只发送一个EXE。包内需保留WoWProbe插件、资源和所用路线；目标电脑运行程序不需要开发用的Python。当前实测环境为Windows11、Forever1.60.1、盗贼。

1. 将随包WoWProbe文件夹放入对方实际客户端的Interface/AddOns，并在角色界面启用或游戏内/reload，确认左上色块及血条可见。
2. 核对角色职业与技能：2邪恶攻击、4切割、3剔骨、9闪避、=食物；需要剥皮时，将已学的当前等级剥皮放在7，并备刀。其他职业不能直接套用此技能循环。
3. 核对F交互、Tab选怪、W/S移动、左右方向键转身，以及点击移动设置。A/D可能已被改为平移，不能按默认键位猜测。分辨率、UI缩放和操作系统缩放变化后，确认色块能持续解码，再标定移动与转向。
4. 为对方角色所在地图准备墓地到打怪区的跑尸路线，校准坐标尺度、转速和移动速度。当前附近入口仍使用本机标定参数，不能声称已自动适配其他电脑；随包洛克莫丹路线也不能代替其他区域路线。
5. 装备预先修好，食物备足，背包留空位，站在适合等级的黄名怪附近。先有人看护完成多轮战斗及恢复验证，再判断能否交付该环境。

启动会核对新鲜插件状态、聊天框、背包、已确认的食物数量和勾选的剥皮绑定，并在日志中说明跑尸路线是否与当前地图匹配。不匹配或缺失时不会执行死亡恢复；匹配也仍受墓地起点、尸体末端接入范围及本机标定限制。这些检查尚不能代替全部首次配置。

## 当前点击开始的含义

启动后只运行已配置的附近战斗、恢复与匹配路线跑尸。包满、食物不足、无法确认转向、持续卡住、失焦或超时等情况会停止，不会自行修理或售卖。每轮最长10分钟、最多复活3次，F12按住急停。

测试记录保存在程序旁runtime。应分别核对真实击杀、拾取、剥皮、恢复与复活事件；不能只依据人物在动或键盘有输入判断成功。当前E盘原0.7.2包与后续仓库联调构建需分开识别，新改动尚不能冒充已在其他电脑验证。
