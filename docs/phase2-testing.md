# 第二阶段路线录制与巡航说明

版本 0.2.0。第一阶段接口暂按可用开发，游戏电脑的实际客户端与地图仍待验证。此版本提供路线系统，不执行自动选怪、战斗、剥皮、复活或售卖。

## 现在没有游戏也能验证的流程

1. 解压 WoWProbe-Phase2.zip，双击 WoWProbe.exe；点击主窗口底部“路线录制与巡航”。
2. 路线窗口默认载入“离线方形演示”。也可载入包内 routes/examples/simulation-square.json。
3. 点击“开始离线模拟”。绿点表示虚拟角色，橙点表示下一目标。模拟不请求真实按键后端，也不依赖游戏画面。
4. 停止后可勾选“反向”再模拟，观察点位按相反顺序排列。勾选“循环”只允许已经录制回起点附近的闭合路线。
5. 可勾选“模拟前进受阻”，观察跳跃、侧移、回退已确认路点和最终停止；这是二维模拟场景，不代表真实地形避障已经验证。
6. 点击“导出本轮记录”，查看 reports/route-时间 下的 route-report.json 与 events.txt。模拟记录会明确标记系统按键数为 0，游戏验证为 pending。

进入模拟会取消第一阶段尚未完成的单次按键；模拟、录制或真实巡航正在进行时，主窗口不能再启动单次按键测试。

## 游戏电脑上的路线录制

先按主窗口说明安装第一阶段插件并建立有效状态读取。录制使用当前插件坐标，不能用演示路线代替实际地图路线。

1. 输入路线名称，选择 farm、corpse_run 或 vendor_return。这三个分类目前用于保存路线用途，未接入死亡或售卖流程。
2. 把角色移到起点，点击“开始录制游戏位置”，起点会自动保存。
3. 手动移动；在转弯、坡道及障碍物前后点击“保存当前位置”。重复点过近时不会重复添加；地图、地图模式或区域改变时拒绝继续混录。
4. 至少录制两个不同位置，再点击“结束录制”和“保存路线”。
5. 需要循环时，必须手动走回起点附近并再次保存，录入完整的回程；勾选循环不能替你生成回程路径。

保存与载入时会检查文件版本、点数、数值范围和地图身份。路线名称可用中文。示例路线绑定的是模拟地图，真实巡航不会把它当成当前游戏地图。

## 标定参数的含义

界面默认参数仅供模拟与初始调整。真实巡航前，需要在当前地图、同一角色移动状态下核对。

- 地图横纵比：地图横向世界距离尺度与纵向尺度的比例。已知地图真实长宽时可直接换算；也可在平坦地面保持相同前进速度，分别向东西和南北走相同时间，用两次归一化坐标变化估算 abs(南北ΔY) / abs(东西ΔX)。
- 北向原始值：手动把角色面向地图正北，点击“记录北向”。当前游戏地图、模式与区域必须和载入路线相同；不可读或危险状态不记录。
- 方向：右转时原始朝向增加选 +1，减少选 -1。比较角度时要考虑 0 与 2π 的环绕。
- 转速 rad/s：原地转向的角度变化除以实际按住秒数。短时间、多次测量；避免转过半圈以上后直接用角度差估算。
- 移动速度：在相同移动状态下测得的归一化纵向单位每秒。计算 sqrt((ΔX×横纵比)²+ΔY²) / 秒数。坐骑、减速和水中移动会改变该值。
- 转向键：选 Q/E 或 A/D；另一对作为平移，W 前进、S 后退、空格跳跃。先在游戏按键设置里核对。

可以保存或载入标定文件。载入时检查地图身份，确认勾选不会自动恢复；每次真实巡航仍需手动确认。

## 真实巡航与断点

1. 先模拟当前路线，确认方向和文件内容；把角色手动移到所选起点附近。
2. 选择“从第一个点”“最近路点”或“保存的断点”。最近点接入仍是短距离直线移动，请先保证当前位置到该点可通行。
3. 核对标定、转向与平移键，关闭聊天框和菜单，勾选确认。点击“真实巡航（5秒后）”，切回游戏。
4. 程序逐次短按前进或转向；每次释放后等待新的状态帧再规划下一次。没有开启自动奔跑。
5. 按 F12、鼠标移入主屏左上角、点击停止或关闭窗口，均会停止并释放本工具按键。失焦、数据过期、API读取失败、死亡、灵魂、战斗、背包满及地图变化也会停止，不自动继续。

断点位于工具旁 routes/user，绑定完整路线内容、地图模式、区域、正反方向及循环设置。更换路线内容或模式后不能套用旧断点。已完成的断点不会自动重新开始；要重新跑应选择起点。模拟不会覆盖实际巡航进度。

若输入发送或释放报错，整个工具会锁定后续输入；换路线、换窗口或重建会话不能绕过。需手动松开相关按键，检查角色状态和运行权限，再重启工具。

## 卡住处理的范围

只有实际发出前进命令而位移长期不足时才累计卡住时间，等待、转向和重复帧不会被当成前进。恢复最多三次：短跳、短侧移、返回本次运行已到过的上一个路点。仍失败、无可回退路点或节点超时则停止，不直接跳过障碍物去下一点。

这套逻辑使用录制路点，不具备完整地图网格、悬崖检测或通用寻路。实机先选择平坦、短距离的少量路点，逐项检查后再扩展范围。

## 本轮待实机确认

第一阶段接口与色块读取、真实坐标尺度、北向与旋转方向、按键实际效果、转弯误差、卡住处理、失焦及F12释放、断点恢复与往返路线。测试结果请导出完整目录，并附必要的画面和复现步骤。
