# 固定路线录点与打怪

## 2026-11-18 测试版更新

当前窗口应显示“拾取修复版0.7.4”。修复尸体重选命令被自身聊天保护中断的问题；上一目标重选失败后会按完整名字重试，再校验原尸体身份。剥皮必须脱战；途中再次受到攻击会取消本次剥皮、优先反击，之后恢复尸体处理。此版本已通过命令流程及状态回归，实际游戏效果仍待测试确认。

新版测试入口：`E:\WOW\新版测试\启动自动打怪.cmd`。保留已录路线，启动和击杀后的尸体处理完成后优先找附近目标，没有合适目标再前往最近巡航点。

“载入方案”和“导入路线”均自动识别旧巡航方案、旧版打怪路线及录点草稿。旧文件缺少追怪/技能设置时使用默认值；旧版打怪路线导入后补回A，原文件不改。跑尸、商人路线请在各自用途配置。

在“技能设置”输入“每只怪开场一次”和“之后重复循环”。例如开场242223、循环2；若想整段反复242223，可把开场留空、循环填242223。技能间隔支持0.10–5.00秒手填，默认0.75秒。配置随巡航方案保存。

击杀后战斗标记的短暂延迟会等待清除，再重选同一尸体拾取和剥皮；真实新攻击优先处理，之后恢复待处理尸体。该修复的开发侧检查已通过，实机结果由本轮测试确认。

打开 `启动自动打怪.cmd` 后只显示配置界面，不自动控制游戏。

1. 手动走到A点，停下并脱战，点击“保存当前巡航点”。程序只读取角色当前位置，自动记录地图和坐标。
2. 走到B、C、D等位置，每到一处再次点击同一按钮，依次追加路点。每次录点立即保存 `quick-patrol-recording.json` 草稿，重开可以继续录。
3. 点击“闭合到起点”，补上返回A，形成A→B→C→D→A。表格也可手工填写0–100坐标；完整方案可以另存和载入。
4. 点击“开始自动打怪”，使用界面当前移动参数；程序在任何移动前核对当前地图、新鲜状态和角色条件，五秒倒计时后接管。不再以未勾选参数确认阻止启动。新电脑仍需根据实际方向和速度调整参数。
5. “停止”或F12停止。切走游戏窗口也会停止，需重新点击开始。

角色在同地图但不在路线上时，先前往最近巡航点，从该点的下一个点继续。沿路线前进并扫描，无怪时继续下一点，不因空点停下。附近黄名目标可以离开巡航走廊，用已确认的F交互接近和面向；默认主动追怪范围为距路线2个坐标点，可在参数页修改。主动接近12秒未进入战斗或到达追怪边界会放弃目标并返回原路段，短时间跳过该目标。战斗、拾取、剥皮和吃喝后回到原路段继续。受到攻击优先处理可验证敌对目标，返回路线和吃喝也可被防御战斗中断；包满在战斗结束后停止。

已选中且插件确认可剥皮的路边尸体会先接近、处理必要拾取，再按7剥皮，不增加本轮击杀数。当前未实现自动从场景中发现并选中所有白名尸体，白名本身不代表可剥皮。此能力待下一步接入，不能标为路边尸体自动发现已通过。

不能通行的路段需要增加中间路点；持续无位移或超出主动追怪/允许返回范围会停止。闭合后继续录点会先移除末尾返回A，再追加新点，请最后重新闭合。

每台电脑单独录点、核对地图和移动参数；导入方案不会替该电脑确认标定。默认横纵比1.5、朝向系数-1、转速5.85rad/s、移动速度0.008仅为可编辑初值，不能代替实际标定。

当前最多运行10分钟。跑尸必须另配同地图跑尸路线；当前包满停止。商人NPC坐标、对话选项与自动售卖往返是下一项开发，不在此录点版中冒充已完成。

开发侧闭环、路线范围、战斗中断恢复和界面录点检查通过；本次尚未进行实际游戏沿用户录制路线的连续击杀验收。已有附近打怪实测见 `live-combat-2026-11-17.md`，两者分别记录。
