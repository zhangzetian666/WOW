# 固定路线录点与打怪

打开 `启动自动打怪.cmd` 后只显示配置界面，不自动控制游戏。

1. 手动走到A点，停下并脱战，点击“保存当前巡航点”。程序只读取角色当前位置，自动记录地图和坐标。
2. 走到B、C、D等位置，每到一处再次点击同一按钮，依次追加路点。每次录点立即保存 `quick-patrol-recording.json` 草稿，重开可以继续录。
3. 点击“闭合到起点”，补上返回A，形成A→B→C→D→A。表格也可手工填写0–100坐标；完整方案可以另存和载入。
4. 在“本机地图与移动参数”核对本机参数，并勾选已核对。角色置于录制路线附近，点击“开始自动打怪”，五秒倒计时后接管。
5. “停止”或F12停止。切走游戏窗口也会停止，需重新点击开始。

巡航按输入顺序循环，只在路线走廊范围内寻怪；战斗、拾取、剥皮和吃喝后回到原路段继续。目标坐标未知时沿路线走近尝试攻击，不会向远方盲目追怪。不能通行的路段需要增加中间路点；持续无位移或超出路线范围会停止。闭合后继续录点会先移除末尾返回A，再追加新点，请最后重新闭合。

每台电脑单独录点、核对地图和移动参数；导入方案不会替该电脑确认标定。默认横纵比1.5、朝向系数-1、转速5.85rad/s、移动速度0.008仅为可编辑初值，不能代替实际标定。

当前最多运行10分钟。跑尸必须另配同地图跑尸路线；当前包满停止。商人NPC坐标、对话选项与自动售卖往返是下一项开发，不在此录点版中冒充已完成。
