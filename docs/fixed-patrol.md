# 固定路线录点与打怪

当前版本0.8.2，配套只读插件0.5.5。窗口标题为“固定路线自动打怪 · 战斗脱困版 0.8.2”。更新执行文件和插件后，在游戏输入`/reload`；新增协议字段不支持旧执行文件。旧巡航JSON缺少恢复、售卖和修理设置时，使用恢复阈值80%、售卖及修理关闭的默认值。

## 2026-11-18 测试版更新

支持持续运行，不再十分钟自动结束。巡航中约2.5秒没有实际位移时，后退、按住鼠标右键换方向；右键未改变实际朝向则使用方向键备用转向，确认朝向变化后短距离试走，再继续路线。两种转向均无效、同一路点三次脱困失败或两分钟未到达路点会停止；坐标导航不能代替复杂地形寻路，需要绕行路点。失焦、F12、补给耗尽或状态失效仍会停止。

战斗中持续3.5秒无成功施法时也尝试后退、换向和试走，解除遮挡后再用F接近原攻击者；实际成功施法会重置检测。战斗中不因旧单怪45秒规则停止后任由攻击；持续自卫，死亡后接入跑尸。各种障碍下的效果仍须分别实机验收。

“恢复设置”可填写生命阈值30–95%，默认80%；低于阈值时脱战吃食物，观察恢复至99%后继续。启动、复活后先恢复。食物放在主动作条第12格（`=`）；法力职业可填写饮水键，盗贼能量不触发饮水。吃喝期间受攻击优先反击，不能边移动边保持食物恢复。

“自动售卖”和“自动修理”各自支持输入0–100坐标或保存角色当前位置，也可填写NPC完整名称。先走到实际NPC旁录入，再保存方案。未填写坐标时不要启用。包满/装备耐久实际降至0时，脱战后分别触发；手动按钮可立即发起对应行程。修理优先于售卖。

到NPC处使用原生交互，若出现真实的“我想看看你的货物”选项则点击。售卖依赖当前客户端已有的自动清包功能，脚本等待真实背包事件及空位增加；不自动逐格出售物品，物品保护须在客户端的自动售卖功能中配置。修理点击真实全部修理按钮，并确认装备耐久恢复满。完成并关闭商店后返回中断位置继续巡航；没有实际结果会超时停止，不把一次点击记为成功。NPC往返目前使用坐标直达，复杂地形可能需要人工重新选择位置。

死亡时立即保存实际死亡坐标，释放灵魂后从墓地以灵魂状态走回实际尸体；不与天使对话、不点灵魂医者复活。只在真实“现在复活”弹窗出现、冷却结束且按钮可用时接受；连续两帧存活后吃喝并恢复巡航。已有同地图跑尸路线可辅助部分路段，不再强制要求预录路线覆盖尸体末端。十分钟内三次恢复后再次死亡会停止检查，长时间分散的偶发死亡不累计成整夜三次上限。

拾取、剥皮保留原尸体身份并等待脱战；剥皮途中受到可验证攻击时取消施法、先反击，再处理待办尸体。按键调试事件只写文件，界面过滤`KeyUp VK=87`等信息；VK87是松开W，真正停止原因见日志最后的“停止”。

新版测试入口：`E:\WOW\新版测试\启动自动打怪.cmd`。保留已录路线，启动和击杀后的尸体处理完成后优先找附近目标，没有合适目标再前往最近巡航点。

“载入方案”和“导入路线”均自动识别旧巡航方案、旧版打怪路线及录点草稿。旧文件缺少追怪/技能设置时使用默认值；旧版打怪路线导入后补回A，原文件不改。跑尸、商人路线请在各自用途配置。

在“技能设置”输入“每只怪开场一次”和“之后重复循环”。例如开场242223、循环2；若想整段反复242223，可把开场留空、循环填242223。技能间隔支持0.10–5.00秒手填，默认0.75秒。配置随巡航方案保存。

击杀后战斗标记的短暂延迟会等待清除，再重选同一尸体拾取和剥皮；真实新攻击优先处理，之后恢复待处理尸体。该修复的开发侧检查已通过，实机结果由本轮测试确认。

打开 `启动自动打怪.cmd` 后只显示配置界面，不自动控制游戏。

1. 手动走到A点，停下并脱战，点击“保存当前巡航点”。程序只读取角色当前位置，自动记录地图和坐标。
2. 走到B、C、D等位置，每到一处再次点击同一按钮，依次追加路点。每次录点立即保存 `quick-patrol-recording.json` 草稿，重开可以继续录。
3. 点击“闭合到起点”，补上返回A，形成A→B→C→D→A。表格也可手工填写0–100坐标；完整方案可以另存和载入。
4. 点击“开始自动打怪”，使用界面当前移动参数；程序在任何移动前核对当前地图、新鲜状态和角色条件，五秒倒计时后接管。不再以未勾选参数确认阻止启动。新电脑仍需根据实际方向和速度调整参数。
5. “停止”或F12停止。切走游戏窗口也会停止，需重新点击开始。

角色在同地图启动时先移动扫描当前位置附近；击杀、尸体处理或恢复后也先找附近下一只。约2.5秒无目标则接入最近巡航点，从该点的下一个点继续。沿路线前进并扫描，无怪时继续下一点。附近黄名目标可以离开巡航走廊，用F交互接近和面向；默认主动追怪范围为距路线2个坐标点，可在参数页修改。主动接近12秒未进入战斗或到达追怪边界会放弃并短时跳过。跳过其他人占有或正在战斗的活怪；自身受到攻击优先反击。包满时若未配置售卖NPC，在脱战后停止。

已选中且插件确认可剥皮的路边尸体会先接近、处理必要拾取，再按7剥皮，不增加本轮击杀数。当前未实现自动从场景中发现并选中所有白名尸体，白名本身不代表可剥皮。此能力待下一步接入，不能标为路边尸体自动发现已通过。

不能通行的路段需要增加中间路点。脱战偏离路线时自动接入最近路点；战斗追击有边界，不无限远追。闭合后继续录点会先移除末尾返回A，再追加新点，请最后重新闭合。

每台电脑单独录点、核对地图和移动参数；导入方案不会替该电脑确认标定。默认横纵比1.5、朝向系数-1、转速5.85rad/s、移动速度0.008仅为可编辑初值，不能代替实际标定。

运行证据位于执行文件旁`runtime/quick-时间.log`、`-frames.tsv`及击杀/拾取/剥皮截图。0.8.0的开发侧领域、协议、Lua及配置界面检查通过；真实NPC售卖/修理、各种地形跑尸和整夜稳定性须分别实机确认，不能用模拟结果替代。已有附近打怪实测见`live-combat-2026-11-17.md`，本轮更新见`progress.md`。
