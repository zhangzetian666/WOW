# 第一阶段开发侧验证记录

版本 0.1.0　日期 2026年11月11日

## 已完成的开发侧验证

- C# 5 和 .NET Framework 编译成功。
- 核心测试 43 项通过、0 项失败：数据校验、未知字段、UTF8、色块编码、心跳超时、持续输入资格、单次按键计时、失焦、F12、异常释放和并发停止。
- Windows 边界测试 5 项通过、0 项失败：截图边界、负坐标、多屏区域以及 32/64 位 INPUT 结构大小。
- Lua 5.1 测试 29 项通过、0 项失败：缺失接口、异常接口、旧版与现代地图候选、非蓝条资源、背包、UTF8、事件状态、已知状态位及物理像素缩放。
- Lua 实际生成的 128 字节数据包由 C# 成功解析，名称、坐标、资源类型和校验和一致。
- 在开发电脑显示专用模拟色块，使用真实桌面截图读取并解析成功；该测试未连接游戏。
- Windows 检测界面已启动并检查布局。模拟测试代码编译为独立测试程序，不包含在交付的 WoWProbe.exe 中。

以上 77 项自动测试及交叉解析、截图验证均已通过。按键保护测试使用内存后端，没有向游戏或其他应用发送真实按键。

## 独立审查与修正

独立代码审查发现并修复了三项问题：物理像素与游戏界面单位的换算；倒计时中字段读取失败时持续阻止按键；布尔状态读取失败时明确显示不可读。相关测试先复现失败，再在修复后通过，并重新运行了全套检查。

实际客户端版本、插件能否加载、真实画面下色块尺寸、游戏接口限制、按键实际效果、目标交互、剥皮、死亡和包满事件，以及 SavedVariables 正常保存。

## 开发侧复现

在源代码目录运行 verify.ps1，并用 PythonPath 指向包含 lupa.lua51 的 Python 3.12；脚本会重新编译、执行 C# 和 Lua 测试、交叉解析及桌面截图验证。完整运行输出保存在源项目 test-output/verification.log。

源项目路径 D:\software\WOW\phase1。游戏电脑直接使用测试包中的可执行程序，不需要这些开发依赖。
