# 0.8.48 随机技能、路线与定时休息

## 技能设置

填写五行中的任意一行或多行，留空行不参与选择。每只新怪锁定时随机选一行，本次战斗循环执行该行；接近、重试或施放失败不会重新选行。日志显示“随机技能行N=按键”。4、5终结技失败补2的逻辑保留。旧方案的开场顺序迁入第一行，开场为空时使用旧循环顺序。

## 随机路线与休息

“启用随机路线”开启后，原巡航路线加20条变体，NPC原路线加10条变体，跑尸原路线加5条变体。完成录制后自动保存已具备条件的变体，也可点击“生成并保存随机路线”。文件在客户端旁的random-routes目录，以patrol/npc/corpse区分类型，00为原路，其余名称为“随机路线N”。未录制的路线不会凭空生成；不匹配当前地图的跑尸路线不生成。

变体保留所有原转角和起终点，仅在路段中添加有界偏移点，默认最大偏移0.06个地图坐标点，并进一步限制在巡航允许偏离的四分之一内。此算法不读取地形碰撞信息，不能证明附近位置可通行；建议先短程验收。相同原路线、偏移和种子生成同一组变体。原路不会被变体覆盖。

启动及每圈完成后随机选巡航路线；NPC去程和返程编号不同，断点保存实际路线和选中编号，重启不重新抽路；每次新建跑尸流程选一条跑尸路线。日志记录选择结果。旧版未完成NPC断点仍沿已保存路径恢复，不强制改道。

勾选定时休息后，从开始运行累计在线时间，包含售卖、修理、跑尸和恢复。生成100个不同的额外秒数（1秒至120分钟），每轮取其中一个，加在两小时之后作为本轮上限；相邻两轮额外时长不同。停止或中断后的等待不累计在线时间。计时用单调时钟，状态保存到quick-session.json。

到点后先完成正在发生的战斗或跑尸，脱战、非施法时打开ESC菜单。通过Windows文字识别核验返回角色菜单按钮，并二次确认角色选择界面后，才开始13、15或18分钟的随机休息。休息结束确认进入游戏按钮后按回车；收到新鲜游戏状态且地图匹配才恢复巡航。断线、加载、登录页或读取失败不会被当作角色选择界面。未能识别时保留等待状态并记录原因，不填写账号密码。可用停止/F12取消。

菜单识别需要Windows OCR语言组件及assets/read-menu.ps1，支持中文常见按钮文字和部分英文别名。窗口须在输入时处于前台；休息期间可以使用其他窗口。不同客户端菜单文案、缩放及字体仍需实测。菜单流程日志另存quick-session.log，全程不保存截图。
