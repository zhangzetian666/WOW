# 鼠标键盘移动实测（2026-11-17）

环境：Forever 1.60.1，铁炉堡地图1455，角色存活、满血、脱战。以下来自本轮实机操作与插件只读坐标/角色朝向，不把镜头变化直接当作角色转向。

## 当前角色的操作

| 输入 | 实机结果 |
| --- | --- |
| 按住左键拖动 | 镜头绕角色旋转；坐标和角色朝向保持不变 |
| 按住右键横向拖动 | 改变角色朝向；先前镜头独立转动时，开始右键操作还会使角色跟随镜头方向 |
| 按住右键上下拖动 | 改变镜头俯仰；单独竖向测试时坐标及水平朝向不变 |
| W | 沿角色当前朝向前进，松开后停止 |
| S | 后退，水平朝向不变 |
| 左/右方向键 | 原地左转/右转，位置不变 |
| A/D | 此角色实际绑定为 STRAFELEFT/STRAFERIGHT，左右平移；不是原地转身 |
| 右键单击可行走地面 | autoInteract=1 时自动转向、走到所点位置后停止；无需同时按W |

BUTTON1 实际绑定 CAMERAORSELECTORMOVE，BUTTON2 绑定 TURNORACTION。Q/E 已绑定技能，移动校准不使用这两个键。

## 校准工具与后续接入

仓库构建新增 `bin/WoWProbe.exe look <dx> <dy>`，每轴限制160，分段相对移动；实际按住右键并在正常结束、失焦或异常时释放。拒绝用户已按住鼠标或Shift/Ctrl/Alt的情况，并打印前后朝向、坐标。沿用前台、F12急停、地图身份及新鲜状态检查，只允许存活、脱战、聊天框关闭时校准。

`move strafeleft/straferight <40..1500ms>` 对应本角色已核实的A/D绑定。移动和转向速度受当前客户端与设置影响，不能把本轮弧度变化硬编码为通用灵敏度。

发现早先现成拖动接口仅支持左键，传入未定义的右键参数不会得到右键拖动，已纠正。点击移动恢复为autoInteract=1并读取确认。右键拖动、单击地面和右键交互目标是不同动作，后续分别处理。

脚本接入原则：先停止旧移动，再转向，确认角色朝向与实际位移；选择可见、可行走地面点击，持续检查是否前进、到达或卡住。短通道两次点击成功不代表任意障碍寻路成功。本轮未重新执行连续击杀、拾取剥皮或死亡恢复验收。

完整代码回归：`test-output/verification-mouse-controls.log` 为VERIFICATION_OK，包括鼠标按钮在异常时释放的回归及既有C#/Lua/协议检查；跳过桌面与完整工作流UI套件。E盘启动包仍为原0.7.2，本轮操作记录单独保存，不冒充新版战斗包已验收。
