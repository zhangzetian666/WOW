# 独立钓鱼客户端（FISHING）

2026-11-28 用户要求：从 main 的钓鱼核心和已验证路线/商人代码整理独立客户端，源码在同一仓库 FISHING 分支维护，不改变 main/chief。

- 抛竿前随机延迟范围（秒），默认0.3–1；每杆重新抽样。
- 收杆延迟范围（秒），默认0–1；每杆单次F，延迟上限1秒且不能超出当前鱼讯/施法窗口。
- 静音时支持本杆浮标区域的水花图像变化识别；音频环回并存，两个来源去重，不把固定超时当鱼讯。仅在内存中处理画面，不保存游戏截图或原始声音。
- 保存三个同图钓点及面水朝向；启用随机钓点后沿AB、BC、CA线段依次轮换，每次取线段上的随机位置。朝向按该段端点朝向做圆周插值。用户确认三条连线在可行走岸边；不能从坐标证明地形可通行。
- 已确认：各线段轮换一次算一圈；每点驻留可配置，默认10分钟，当前杆结束再换点。
- 可选随机背包查看，最短/最长分钟设置，默认10–15；按B打开，3秒后B关闭，每次重新抽间隔，当前杆结束后执行到期动作。
- 复用录制NPC路线、坐标保存、包满前往售卖/维修并原路返回；钓鱼客户端只展示钓鱼设置。
- 内置1000条中文简短交流话术，圈末随机一条发到普通说话频道；可开关。私信首次回复“这会有个电话，稍等回你”，同角色再次回复“稍等”。只针对新收到的私信，按R前核对当前最后私信发送者；用户明确授权此回复功能。
- 可选在线时长随机范围（小时）与离线时长随机范围（小时），默认分别1–2。在线到期先完成当前杆，ESC→实际登出按钮；确认角色选择界面才计离线时长。到期进入角色，确认有效同图状态后继续，重新抽在线时长。
- 掉到账号登录界面时核对可见确定/登录按钮后进入已保存会话；不保存、输出或猜测账号密码。需用户输入的登录条件在界面显示，继续等待。
- F12急停、显式停止、前台和按键所有权保留；本地测试与实机验证分开。没有实际钓鱼反馈不得标记收获成功。

## 交付顺序

1. 核心随机延迟、静音视觉输入与回归测试。
2. 独立配置/三点/NPC录制、定时背包/聊天/上下线控制。
3. 原生适配与插件私信只读反馈、1000条话术和打包。
4. 本地测试、界面检查、部署打开、提交并推送FISHING；实机需要保存真实钓点和浮标观察区域。

声音依据：[Microsoft WASAPI loopback](https://learn.microsoft.com/en-us/windows/win32/coreaudio/loopback-recording)读取播放混音，静音效果与音量层级/设备有关，不能承诺所有静音状态仍有信号；程序检测实际声音数据并提供独立视觉来源。
