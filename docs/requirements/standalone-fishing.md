# 独立钓鱼客户端（FISHING）

2026-11-28 用户要求：从 main 的钓鱼核心和已验证路线/商人代码整理独立客户端，源码在同一仓库 FISHING 分支维护，不改变 main/chief。

- 抛竿前随机延迟范围（秒），默认0.3–1；每杆重新抽样。
- 收杆延迟范围（秒），默认0–1；每杆单次F，延迟上限1秒且不能超出当前鱼讯/施法窗口。
- 静音时支持本杆浮标区域的水花图像变化识别；音频环回并存，两个来源去重，不把固定超时当鱼讯。仅在内存中处理画面，不保存游戏截图或原始声音。
- 保存三个同图钓点及面水朝向；启用随机钓点后沿AB、BC、CA线段依次轮换，每次取线段上的随机位置。朝向按该段端点朝向做圆周插值。用户确认三条连线在可行走岸边；不能从坐标证明地形可通行。
- 已确认：各线段轮换一次算一圈；每点驻留可配置，默认10分钟，当前杆结束再换点。
- 可选随机背包查看，最短/最长分钟设置，默认10–15；按B打开，3秒后B关闭，每次重新抽间隔，当前杆结束后执行到期动作。
- 复用录制NPC路线、坐标保存、包满前往售卖/维修并原路返回；钓鱼客户端只展示钓鱼设置。
- 内置1000条中文简短交流话术，圈末随机一条发到普通说话频道；可开关。私信首次回复“这会有个电话，稍等回你”，同角色再次回复“稍等”。只针对新收到的私信，按R前核对当前最后私信发送者；用户明确授权此回复功能。
- 可选在线时长随机范围（小时）与离线时长随机范围（小时），默认分别1–2。在线到期先完成当前杆，ESC→实际登出按钮；确认角色选择/登录/断线画面且世界状态已不可用后才计离线时长。到期进入角色，确认有效同图状态后继续，重新抽在线时长。
- 掉到账号登录界面时核对可见确定/登录按钮后进入已保存会话；不保存、输出或猜测账号密码。需用户输入的登录条件在界面显示，继续等待。
- F12急停、显式停止、前台和按键所有权保留；本地测试与实机验证分开。没有实际钓鱼反馈不得标记收获成功。

## 交付顺序

### 1.0.12 补充需求

- 新增与打怪脚本一致的死亡记点、释放灵魂、录制跑尸路线、从终点接近尸体、按钮复活及返回钓点流程；不与灵魂医者交互。支持存活或灵魂录制、独立草稿、继续/取消及导入原打怪跑尸路线。
- 抛竿前随机等待数值显示红色，收杆随机反应时间显示蓝色。
- 每次保存坐标追加一个钓点，文本框列出编号、坐标及朝向，不覆盖旧 A/B/C。相邻点及末点回首点构成随机钓点连线；允许多点，所有连线轮换一次为一圈。

### 1.0.14 补充需求

- 抛竿后失焦时保留任务，记录实际前台窗口；支持键鼠空闲达到设定重试秒数后自动切回游戏，人工操作期间不切换，停止/F12取消恢复。
- 在线到时等当前杆结束，ESC点击登出后20秒不插入按键；确认离开角色后开始离线等待，到时回车进入当前角色；识别用户截图的WoWProbe受限UI弹窗或插件/Lua错误，双帧确认后只点击“忽略”，不点“禁用”，世界状态稳定后恢复钓鱼并重计在线时间。
- 图像识别和模拟流程验证与游戏内整轮上下线验收分开记录，不把仅发出按键当作完成。

### 1.0.13 补充需求

- 放宽前进速度标定上限，界面与运行校验/导入一致；说明地图归一化单位与游戏码/秒的区别，保留用户当前参数，不把放宽数值当作实际加速。
- 可选聊天扩展反馈缺失不再阻止开始钓鱼；暂缓聊天并继续钓鱼和定时动作，反馈恢复后只处理新消息/新圈次，不取消频道、收件人、前台及急停检查。

### 1.0.11 补充需求

- 背包保持打开时间可输入秒数，默认 3 秒；从实际第一次 B 后计时，时间到再 B，兼容旧配置。
- 确认随机模式是在 AB、BC、CA 连线内部取点，不限于三个端点；到点采用两端保存朝向的圆周插值校正方向。用户保存端点时应面向水面，连线需可通行；不把坐标插值描述为视觉识别水岸。

### 1.0.10 补充需求

- 随机钓点驻留支持最短、最长分钟范围，每次换新点独立抽取，到点后计时，当前杆结束后再换点；兼容旧单值配置。
- 背包查看间隔保留两个输入框，明确最短、最长及分钟单位，每轮重新抽取。
- 新增异常自动重试开关和秒数。运行异常退出后按指定间隔重试有效游戏条件；临时失焦保留任务，等待时间及前台条件满足后继续。停止、F12 和输入发送故障不自动重启。
- 点击开始包含停止旧任务并重新开始，必须等待旧线程退出和释放按键，不并发操作游戏；关闭窗口取消重试。

### 1.0.8 补充需求

- 定时 B 直接完成两次切换，中间等待 3 秒，不依赖聊天/背包扩展插件反馈；保留基础世界状态和前台检查。
- 随机连线到点后先校正为记录的面水朝向，再开始抛竿倒计时。暂时失焦保留任务，回到游戏后继续校正；不能将旧日志中的失焦等同于已证明朝向计算错误。
- 新增可开关的定时数字键，支持 0–9 和最短/最长分钟范围，默认 8、10–15 分钟。每次独立抽取间隔，在当前杆结束后按一次，至少留足 10 秒且读条结束，再重新计时。施法等待期间禁止插入其他自动动作。导入旧配置默认关闭新功能。
