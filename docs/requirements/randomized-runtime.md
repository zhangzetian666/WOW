# 2026-11-23 随机技能、路线及休息需求

本轮实现第1、3、5、6、7项，同步main与chief；同步完成后固定chief，后续新增修改在main。

1. 五行技能顺序，每只新怪随机选择一条非空行，战斗内保持，日志记录行号。
3. 原巡航路线加20条邻近变体，保留端点与关键转角，每圈随机选择并记录编号。
5. 在线累计包含巡航、战斗、售卖、修理和跑尸；两小时后加上从100个候选中随机选择的额外时长，额外最长120分钟；每轮额外时长不与上轮相同。脱战后返回角色菜单，随机休息13/15/18分钟后进入游戏。必须确认角色菜单，读取失败不能当作下线成功。停止/F12可取消。
6. NPC原路加10条变体，去返程选择不同编号，恢复未完成行程时保留已选路线和断点。
7. 跑尸原路加5条变体，每次选择并记录编号。

暂不开发：2手动更换打怪区域；4用户手动聊天；8每天接一个NPC任务。

随机化不保证规避运营商检测或处罚。附近坐标不等于可通行道路，变体限制偏移并保留端点及转角，通行性另行实机验证。
